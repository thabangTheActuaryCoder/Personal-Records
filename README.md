A central, version-controlled store for my personal records.

## Structure

| Folder | Contents |
|---|---|
| [`Qualifications/`](Qualifications/) | Degree certificates, diplomas, proof-of-qualification letters, professional certifications (e.g. CFA, ASSA exemptions) |
| [`Academic-Records/`](Academic-Records/) | Official transcripts and academic records (UFS, UCT) |
| [`Reference-Letters/`](Reference-Letters/) | Reference and recommendation letters from supervisors, employers, and academics |
| [`Thesis/`](Thesis/) | Dissertations and theses — `Honours/`, `MSc/`, `PhD/` |
| [`CV/`](CV/) | CVs with LaTeX source and compiled PDF — `Academic/` (academic positions, PhD), `Corporate/` (industry roles), and `Mixed/` (hybrid academic + industry posts, e.g. lecturer roles requiring both teaching/research and industry experience) |
| [`Combined/`](Combined/) | Merged multi-document PDF packs for applications (e.g. qualifications and academic records combined into a single file) |

## Suggested naming convention

Keep filenames consistent and searchable:

```
<Institution-or-Issuer>_<DocumentType>_<Year>.pdf

Examples:
UFS_MSc-Mathematical-Statistics-Certificate_2026.pdf
UFS_Academic-Record_2026.pdf
UCT_BScHons-Statistics-DataScience-Transcript_2025.pdf
Discovery_Reference-Letter_2022.pdf
```

## Notes

- This repo is **private** — review GitHub's collaborator/visibility settings before sharing anything.
- Prefer PDFs for official documents.
- Large scans: consider compressing before committing to keep the repo lightweight.
